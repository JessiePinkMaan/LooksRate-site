# QA_AND_RISKS — протокол проверки, рубрика «вайба», риски

Создан в Фазе 1 (до первой UI-фазы). Используется на конце каждой UI-фазы.

## Рубрика «вайба» — 10 пунктов × 0–2 балла = 20

Оцениваем по скриншотам `pnpm qa:shots` (4 ширины) и вживую.

| # | Критерий | 0 | 1 | 2 |
|---|---|---|---|---|
| 1 | **Тёмный вайб и палитра** | светлое/пёстрое | тёмное, но грязно | `void/basement`, красный ≤8%, золото только яблоко/ранг |
| 2 | **Типографика** | дефолтный шрифт | один шрифт | контраст display/heading/mono/body, кириллица, крупный hero |
| 3 | **Фактуры** | плоский фон | лёгкое зерно | зерно + бетон + виньетка, без «шума» |
| 4 | **Фурнитура** | нет деталей | пара деталей | заклёпки, «строчка», ремни — уместно, без эротики |
| 5 | **Курсор и микро** | системный курсор | точка | красная точка + кольцо, «тяжёлые» ховеры |
| 6 | **Hold-взаимодействие** | обычная кнопка | есть прогресс | удержание как UX, понятный прогресс, отмена |
| 7 | **Движение** | дёрганое/нет | есть анимации | осмысленно, 0.7–1.2 с, reduced-motion fallback |
| 8 | **Композиция** | каша | сетка есть | воздух, «комнаты», не «бизнес-лендинг» |
| 9 | **Читаемость/a11y** | нечитаемо | контраст ок | ≥4.5:1, focus-ring, клавиатура |
| 10 | **Целостность** | набор кусков | стиль читается | один мир: подвал/яблоко/стоа |

**Порог:** ≥14/20 — приемлемо. <14 после 3 кругов правок — зафиксировать в отчёте, не застревать.

## Обязательные проверки на UI-фазе

- `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build` — зелёные.
- `pnpm qa:shots` — скриншоты 4 ширин в `qa/shots/<phase>/`.
- `prefers-reduced-motion` — все эффекты заменяются кросс-фейдом/статикой.
- Кнопка «Отключить эффекты» — работает глобально.
- Нет стробоскопа (>3 вспышек/с), мерцание лампы ≤ ±10%.
- Focus-ring видим, навигация с клавиатуры.
- Нет `console.error` на странице.

## Риски

| Риск | Что делаем |
|---|---|
| Фотосенситивность | ≤3 вспышек/с, без высококонтрастного мерцания >25% площади (WCAG 2.3.1) |
| Производительность | начальный JS ≤250 КБ, LCP <2.5 с, авто-деградация эффектов |
| Доступность | контраст ≥4.5:1, reduced-motion, клавиатура, aria у сцен |
| Контент-гардрейлы | без эротики, без опасных инструкций, без дегуманизирующей лексики |
| Юридическое | 18+ гейт, юр-страницы, согласия (шаблоны; финал — владелец/юрист) |
| Секреты | только env; `.env` в `.gitignore`; проверка gitleaks |
| Реальные люди | фото — только с согласия; чужие фото из сети не берём (силуэты — ок) |
